## 2026-10-30

**一句话速览**：昨天说「权重没来」的那件事，今天来了——**Mistral Large 4「Le Chonk」**在 Hugging Face 开放权重，1 万亿参数、1M 上下文、允许商用但 MaaS 要单独授权，API 输出价直接砍到原来的四分之一。TanStack 一周内连交两份作业：**AI 1.0** 稳定（23 个 provider 适配器）与 **DB 1.0 RC1**（用 42 万行「oracle」测试给自己上强度）。Claude Code 补上一条真正硬的护栏：**工作目录外的写入在任何权限模式下都会被拒**，包括 `--dangerously-skip-permissions`。产业侧，财报夜把分歧拉满——Alphabet 创下上市以来最大单日跌幅（-12.34%），亚马逊自由现金流 -424 亿美元，英特尔盘后 -23%；同一时间智元把机器人操作系统整条链路开源、三星单季营业利润破 100 万亿韩元。

### 🚀 框架与工具链

- **[TanStack AI 1.0：稳定 API、23 个 provider 适配器、8 个 UI 框架](https://tanstack.com/blog/tanstack-ai-1-0)**（2026-10-23，共 76 个包）：从 8 月的 RC 走到稳定，核心的 chat / voice / image / tools 四套 API 都定了。最实际的收益是**适配器从 alpha 时的 4 个长到 23 个**，外加一个通用的 `openaiCompatible`；新面孔包括 Cloudflare Workers AI / AI Gateway、Lovable AI Gateway、Azure OpenAI、World Labs Marble、TypeSafe、Ollaya 等。UI 层支持 React、Vue、Solid、Svelte、Preact、Angular、Octane、Remix 与原生，并新增 `subscribe` + `send` 的全双工连接适配器与 `createChatHook` 工厂。**升级有三处破坏性变化要按顺序处理**：`useChat` 及其所有 chat hook、`ChatClient`、生成 hook、服务端 `chat()` 现在**必须传 `threadId`**；`body` 改名 `forwardedProps`、`conversationId` 改名 `threadId`；`addToolApprovalResponse()` 被移除，改用 tool-approval interrupt。官方给了 codemod，但⚠️ 还有两条要留意：**1.0 的客户端必须配 1.0 的服务端**（要同版本一起部署），以及 `ai-react-ui` / `ai-solid-ui` / `ai-vue-ui` 这三个包**没有 1.0 版本**；实验性的 `@tanstack/ai-harness`（持久化 Agent 会话）刻意停在 0.x。
- **[TanStack DB 1.0 RC1：把「oracle 测试」当成主菜](https://tanstack.com/blog/tanstack-db-1-0-rc1-going-all-in-on-oracles)**（2026-10-29）：功能上的新东西不算多——**SSR 支持**并与 TanStack Start 深度集成（服务端与浏览器共享 descriptor、但各自持有独立的 `DbClient`，水合时原子替换整个快照）、新增 **Neon Realtime** 与 **Convex** 两个 collection 适配器、加上 **Preact** 成为第六个支持框架、体积与执行速度都有改善。真正的故事在标题里：团队把 Agent 引入硬化流程，为每个包维护**参考模型「oracle」测试**——随机生成操作历史，把真实 DB 的输出与一个独立实现的模型对比。这轮跑出 **211 个 oracle 测试文件、覆盖 15 个包、新增约 42 万行测试**，并且真的抓到了 bug（比如某个订阅者收到 `update`，但它需要的是 `insert`）。迁移从 0.9.2 到 1.0.0-rc.1 有几处要改：`$synced` 更名 `$hasPendingWrites`（语义反转）、`transaction.isPersisted.promise` 换成 `transaction.when('settled')`、查询集合的自动 mutation refetch 被移除、Electric 同步必须 `await collection.utils.awaitTxId(txid)`、React live-query hooks 去掉依赖数组且不透明子句要给可序列化的 `queryKey`。⚠️ 仍是 RC 不是 GA；官方称 `@tanstack/db` 周下载已过 100 万，Prisma Studio、Unkey、Skylight 已在生产用。

### 🎨 浏览器与 CSS

- **[Chrome 159 进入 Dev 频道（159.0.8130.0），同时 `symbols()` 被确认卡在 Safari](https://chromereleases.googleblog.com/2026/10/chrome-dev-for-desktop-update_01100896752.html)**（2026-10-30；发布说明只给了 git log，没有特性清单）：这条本身信息量不大，但可以和另一条一起读——Web Features Explorer 现在把 CSS **`symbols()` 函数**标成「**Baseline 自 2026-10 起被 Safari 阻塞**」：它已经随 **Chrome 155（10-06）与 Edge 155（10-08）** 上线，可以在 `list-style` 里直接内联定义计数器样式（替代 `@counter-style`），但四大引擎缺一家就不算 Baseline。**给组件库的实际含义**：`symbols()` 现在可以「渐进增强」，不能当默认方案；想用它就得留一个 `@counter-style` 的降级分支。此前于 **10-25** 推过「本月新进 Chrome」的清单（`random()`、JPEG XL、`symbols()` 等），这次是**可用范围**的新信息。顺带对齐一下日历：Chrome **158** 仍是 Beta，稳定版定档 **11-17**；**159** 现在才刚进 Dev，离稳定还有两个大版本。

### 🤖 AI 与开发

- **[Mistral Large 4「Le Chonk」开放权重：1 万亿参数、128 专家、1M 上下文](https://huggingface.co/blog/mistral-large4)**（2026-10-29，距 10-06 发布预览约三周）：此前于 **10-28** 推过「放权重日到了、权重没来」（当时 HF 仓库只留占位页、ETA 10-31、LICENSE 404），今天**真的放了**，而且比预告早了两天。规格：总参约 **1 万亿**的 MoE，**128 个路由专家 + 1 个共享专家**，每 token 激活 **4 个专家**（约 **490 亿**激活，含 embedding/输出约 520 亿）；**1M** 上下文；原生多模态（文本 + 图像输入、文本输出）；160+ 语言；在 Mistral 自家欧洲机房用 **3,800 块 Grace Blackwell** 从零训练。三周多的额外 RL 把 **Terminal-Bench 4.0 从 28% 拉到 41%**，AA 编码 Agent 指数约 **48**（与 GLM-5.3 相当但每任务 token 少约 47%）、CyberGym-E2E **79%**、AA 网络指数 51；AA 智能指数 v5 为 **26**，是当前最强的西方开放权重模型（仍落后中国头部模型）。**许可证终于能看清了**：「Mistral Ecosystem Open-Weight License」（**修改版 MIT**）——允许商用，但**以模型即服务（MaaS）形式对外提供需要单独商业授权**；这正是 10-28 那篇好文里悬着的关键未知。生态给得很快：transformers **v5.22.0** 当天支持（`mistralai/Mistral-Large-4-1T-A52B`）、vLLM（含 NVFP4 checkpoint）、llama.cpp / GGUF（Unsloth 还出了 1-bit 版本），量化版可在 **4× B200/B300** 上跑。API 自 10-29 起 **$0.70 / $0.07 缓存 / $2.10** 每百万 token——输入与之前持平，**输出从约 $4.18 砍到 $2.10**。推理强度分 low / medium / high（默认 high，且 high 的效率提升了约 50%）。⚠️ 除 AA 外均为官方口径；1T 模型即便量化也需要多卡，别按「本地跑得动」理解。
- **[Claude Code v2.1.314：工作目录外的写入，任何权限模式都拒](https://code.claude.com/docs/en/changelog)**（2026-10-30，约 50 项修复）：这一版最值得记的是一条**新的硬护栏**——`permissions.blockWritesOutsideWorkingDirectories`，开启后 `Write` / `Edit` / `NotebookEdit` 对**工作目录树之外**的路径一律拒绝，而且**在每一种权限模式下都生效，包括 `--dangerously-skip-permissions`**。对跑在 CI、容器或共享机器上的 Agent，这是第一款不依赖模型自觉的边界；对习惯用「跳过权限」换速度的人，这是个行为变化，要先确认自己的构建脚本有没有写到 `../` 或 `/tmp` 之外。企业侧还有两条：**按 IdP 组做团队路由**，以及 **Bedrock 上的安全过滤日志**（记录事件但**不存储被拦截的文本**）。性能/体验侧：200K 以上上下文会话的空闲压缩、Markdown 表格流式渲染的布局问题、Remote Control 在待切换模型时报错、网关拒绝 beta header 时的重试、带点号的模型 ID（如 `claude-opus-4.8`）解析、Cowork 云会话里的 PDF 文本截断、子 Agent 里 MCP 工具不可用等一批修复；vim 模式的 `dw` / `dW` / `yw` / `yW` 也补上了。此前于 **10-28** 推过 2.1.312（`oidc.user_id_claim` 与 `safety_event` 停发）。
- **[智元创新日：灵渠 OS 1.0 发布并捐赠开放原子基金会，GO-3 Preview 三榜第一](https://www.agibot.com.cn/article/315/detail/261.html)**（2026-10-29，上海世博中心，1000+ 人到场）：这是国内具身智能第一次把**「操作系统」**当成主角而不是附赠品。**灵渠 OS（Link-U OS）1.0** 自称业界首个**具身智能原生操作系统**，覆盖从硬件使能到应用支撑的全栈、已在量产机器人上验证；支持 **15 大类、100+ 外设**即插即用，**1000Hz 任务负载下端到端延迟抖动小于 4 微秒**；计划**年底前全量开源**（约 2 亿行代码、5000+ 生态包），同时智元成为**开放原子开源基金会白金捐赠人**，把灵渠 OS 项目捐出去共建国内人形机器人开源社区。模型侧 **GO-3 Preview** 基于自研 **WRAM（World Reasoning Action Model）**，把推理—预测—动作统一建模，在 **RoboDojo、RoboTwin、RoboColiseum 三个榜上均列第一**，年底开源。另外发布了 **Worken**——一个按「**有效智能工时**」给物理 AI 算生产力的度量衡（意在替代按台数、按小时的计价方式）、全模态交互模型 **WITA-Omni**、「三智一体」硬件平台 **AHA3**、工业机型 **G2 Max** 与 **AGILE** 运动智能框架。公司口径：2026 上半年营收近 **20 亿元**、出货 **9,700 台**（全球份额 43%+），第 2 万台机器人已于 9 月下线。⚠️ 榜单成绩与延迟数字均为官方自测，灵渠 OS 的开源许可证与「2 亿行」的口径（含第三方代码？）都还没公布。
