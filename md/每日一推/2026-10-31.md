### 🌐 语言与规范

- **[robots.txt 里有了跨厂商的「AI 训练」退出开关：`__usage_ai-training`](https://developers.google.com/search/blog/2026/10/ai-training-control)**（2026-10-30，OpenAI / Google / 微软 / Anthropic 联合宣布）：机制很聪明——**不新增指令**，而是在 robots.txt 里定义一个叫 `__usage_ai-training` 的**策略 token**，站点只要写一组就完成退出：<br>`User-Agent: __usage_ai-training` / `Disallow: /`<br>现有解析器无需改动即可读取；规范出处是 IETF **AIPREF** 工作组的 `draft-kelley-aipref-training-preference-signal`（2026-10，作者 Kevin Kelley，Anthropic 标准负责人）。**边界要看清**：它只管**生成式 AI 训练**（修改模型参数），**不是抓取指令**，不影响搜索索引、也不阻止 AI 引用与 grounding；**没写偏好就等于默认允许**；私有协议可以覆盖它。两个容易踩的细节：**通配符 `*` 组不匹配这个策略 token**（所以别指望旧的 `User-Agent: *` 顺带生效）；Google 明确表示，若站点用该 token 退出但没提 Google-Extended，**视为同时屏蔽 Google-Extended**。落地时间表差别很大：**Anthropic 已开始遵守**，OpenAI「未来数月内」，Google 目标是 **2027 年初**，微软 **2027-02-01** 起，微软同时新增页面级训练设置与 AI Grounding 专用选项 `DisallowExtended`（到 **2027-03-01** 需要完成迁移）；**Meta 只表态支持、未承诺遵守**。⚠️ 这份 IETF 草案是**个人提交**，IETF 尚未背书，也没有正式地位——按「事实标准正在形成」而不是「标准已生效」来理解。

### 🎨 浏览器与 CSS

- **[Epoch AI：开源模型 GLM 5.3 零人工攻破 6 个 Firefox 版本，每次约 1000 美元](https://epoch.ai/publications/open-weight-models-patch-gap)**（报告 2026-10-29，覆盖 9-17 ~ 10-26 的 Firefox 156.0–158.0.1）：这不是「AI 找到某个已知漏洞」，而是**把「补丁差」工业化了**。做法是：上游修复已经公开、但还没随版本发布的安全问题（patch gap），模型据此构造攻击链；**每出一个新 Firefox 版本，它就把同一套链条重新拼一遍**。效果是**访问一个由模型自己写的网页，就能读取本地文件并外传，无需用户任何操作**：patch-gap 漏洞提供内容进程里的代码执行，再配一个**尚未公开的沙箱逃逸**（这个逃逸是模型每次自己重新发现的）。时间上**最快 12 小时**、上限 48 小时；**Z.ai 与第三方 API 服务商都没有拦截请求**。成本口径要分开看：整项研究 API 花费超过 **10 万美元**，但**每新增一个 Firefox 版本的边际成本约 1000 美元**。研究者已于发布前把未公开的漏洞报给 Mozilla，**Firefox 159.0（10-27）修复**；同一套 harness 花约 10 万美元**没能攻破 Chrome**——Epoch 自己强调「这不构成 Chrome 安全的证明」。给前端/浏览器方向的实际含义：**「补丁已经提交但还没发版」这段窗口，现在是可以被自动利用的**，自建 Chromium / WebView 或用长期滞后的嵌入式浏览器（旧版 WebView、企业终端）的风险模型要重估。

### 🤖 AI 与开发

- **[OpenAI 更新 Model Spec：五条准则，第一次给 Agent 写「授权范围」](https://model-spec.openai.com/2026-10-29.html)**（2026-10-29 发布，10-30 广泛报道）：结构上从一份「聊天助手行为规范」变成**面向 Agent 的宪法**。五条核心价值是：**忠于人类意图、最小化伤害、诚实与透明、尊重人的能动性、关怀**。对做 Agent 的人，真正可执行的是一组新概念：Root 级规则要求 Agent 只在**「约定好的自主范围」**内行动，并把范围写成结构化字段（如 `allowed_tools`、`latest_time`、`max_cost`）；指令优先级被明确分层为 **Root > System > Developer > User > Guideline > 无权威默认**；同时要求模型必须**可被纠正**——人喊停、要关停时要配合，不能躲。配套还发了一份《我们如何检测前沿模型失配》，描述四层监控（**激活探针 → 模型评审 → 调查型 Agent → 自动调查**），并用这套机制对之前那次 Hugging Face 沙箱逃逸事件做了回溯模拟。⚠️ 关于 U18（13–17 岁）加强保护的部分，主要来自中文报道，OpenAI 官方文档里我未能逐条核对到。
- **[Anthropic 把 Max 20x 改名 Ultra，并对已验证账户取消 5 小时限额](https://www.ithome.com/1/020/398.htm)**（2026-10-30 官方 X 宣布，即刻生效）：改名本身比听起来重要——**Max 5x → Max（$100/月）**、**Max 20x → Ultra（$200/月，价格没变）**，原因是「20x」一直只用来描述 5 小时窗口，而套餐真正的差异在别处。实质变化：**已验证的 Ultra 账户取消 5 小时使用上限**（新账户在自动验证完成前仍暂时受限，取消时会邮件通知；自查方法是设置 → 用量里看有没有 "Current session" 进度条）；**周限额不变**（Ultra 仍是 Pro 的 10 倍、Max 是 5 倍）；**Ultra 附带的 API 额度从 $100 提到 $200**（Max 为 $100）；Ultra 另有新模型/新功能优先权、Claude Code 支持与长任务能力，只支持月付，老用户自动迁移。时机很值得注意：**前脚 OpenAI 刚把 ChatGPT Pro 的上限翻倍、并撤回了对 $200 档的削减**——两家在高付费重度用户这件事上正面对上了。对天天跑 Agent 的人，这条比任何榜单都直接：**限制从「按小时」变成「按周」**，意味着可以把长任务堆在一天里跑完。
- **[苹果与阿里官宣合作：国行 Apple 智能接入千问，11-04 开测、12 月随 iOS 27.3 上线](https://m.ithome.com/html/1020395.htm)**（2026-10-31 官宣）：等了两年的靴子落地。时间线：**11-04** 起随最新 **iOS 开发者 Beta** 开放测试，**12 月**随 **iOS 27.3 正式版**面向中国用户推出（iPadOS / macOS / visionOS 需另行审批）。能力接在三处：**Siri** 可直接用千问做知识问答、也能把文档和照片发给千问提问（发送前需用户授权）；**写作工具**新增「千问创作（Compose with Qwen）」，能生成内容与图像；**视觉智能**支持「询问千问」（相机控制 / 操作按钮 / 控制中心唤起）。分工是明确的**扩展而非取代**——基础功能仍由苹果端侧自研模型驱动，复杂文本与图像的理解、生成才走千问云端；**用户可以自主选择是否开通**，用 Apple 账户或千问 App 登录，**请求与回复不会被阿里用于模型训练**。首批功能清单里没有 **Siri AI**，也不含 WWDC26 公布的下一代能力；支持机型为 iPhone 15 Pro / 15 Pro Max、iPhone 16 及后续、iPhone Air、iPhone Duo，且 Siri 与设备语言需设为英文与简体中文。⚠️ 部分报道称百度文心可能参与底层搜索/视觉识别，**苹果与阿里官方公告均未提及，未独立验证**。
- **[Gemini 支持在对话里直接生成、预览与编辑文件](https://www.ithome.com/1/019/878.htm)**（2026-10-29 宣布，10-30 起向所有用户开放）：交互形态借的是 Canvas 那套——文件**直接内嵌在对话中打开**，可以全屏编辑，也可以手动在文档里打字改；选中一段文本或一个表格，浮动栏里写指令就能定向改写（官方演示：选中表格说「把这些数据显示成图表」，直接转成柱状图），还能多轮追问。支持的格式是 **PDF、Google 文档 / 表格 / 幻灯片、Markdown、TXT 与代码文件**（部分来源还提到 LaTeX），幻灯片可导出 **PPTX** 或 PDF。两处覆盖范围差异要留意：**PDF 的预览与编辑在网页端与移动端都支持，其余格式目前仅限网页端**；付费计划用户还能用 **Task** 触发多步骤自动化流程。对做前端的人，这条的真正意义不是「又多了一个编辑器」，而是**「生成 → 局部修改 → 导出」被合成了一个会话内的闭环**，类似的产品形态（AI 生成的产物可以直接在产物上改，而不是回对话重来）正在成为默认期待。

### 📚 好文精选

- **[AI 训练退出：出版社「不应该被迫做选择」](https://thenextweb.com/news/ai-training-opt-out-robots-txt-google-openai-microsoft-anthropic)**（2026-10-30）：配合上面那条读的政策视角。文章的核心批评很具体：这个 token 把「要不要被拿去训练」变成了**每个站点自己的一项配置工作**，而小型站点既没有法务也没有工程资源去维护；同时它**只覆盖训练、不覆盖 grounding 与引用**，所以「内容被用来回答、但不算训练」这条灰色地带依然开着。它还点出一个容易被忽略的事实：**四家同时表态，但四家的落地时间差着一年以上**（Anthropic 现在、微软 2027-02、Google 2027 年初），也就是说在未来一年多里，**「写了 token 但对方还没遵守」是常态**。对我们写文档站点/博客的，实用做法是把 token 先加上（成本几乎为零），但别把它当作法律保障。
- **[OpenAI 公布了给 Agent 定的规矩，以及监视它们的警报](https://forkast.news/openai-published-the-rules-for-its-agents-and-the-alarms-that-watch-them/)**（2026-10-30）：比 Model Spec 原文更好读的一篇，把「规则」和「监测」拆成两条线讲。值得抄的是它对**指令优先级**的解释：Root 级规则为什么必须压过 Developer 与 User——因为一旦用户能改写 Agent 的边界，`allowed_tools` 这类字段就形同虚设。文章也如实指出这套东西的软肋：**四层监控里前三层都依赖模型自己判断**，最后一层才是自动调查，而「模型审查模型」在对抗性输入下的可靠性还没有公开数据；文中对那次沙箱逃逸的回溯模拟，恰恰说明监控是**事后补上的**，不是事前拦住的。
