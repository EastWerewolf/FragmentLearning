**一句话速览**：今天是**浏览器日**——Chrome 157 进入全量稳定版，同时是 **WebMCP 的去留关口**：给它做支撑的 origin trial 已经随 Chrome 156 结束，如果 157 不默认开启，站点注册的工具对真实访客就直接失效，而 Firefox 明确拒绝、Safari 明确反对。同一时间，**Anthropic 的修订版招股书把「增长在减速」摆上了台面**：Q3 营收 169.6 亿美元、同比近 12 倍，但环比增速从 144% 掉到 47%。产业侧两笔大账：**迈威尔 1150 亿美元全股票收购 Lumentum**（史上最大全股票科技并购），以及国内**推理数据量首次超过训练数据量**——日均词元调用 175 万亿。

### 🎨 浏览器与 CSS

- **[Chrome 157 今天全量稳定，WebMCP 走到「要么 ship、要么滑期」的路口](https://chromestatus.com/release-notes/157)**（2026-11-03 全量稳定版）：这一版的功能清单其实早在 **10-17** 就推过（`corner` 简写、`text-overflow: <string>`、`text-decoration-inset`、`position-visibility: anchor-valid`、单轴滚动容器的 scroll snap、`<camera>` / `<microphone>` / `<geolocation>` 的 `icon-only` 模式、新的 HTML 插入与流式 API `appendHTML()` / `streamAppendHTML()`、HTML-in-Canvas 等），今天真正的新信息是**时间点和一个悬而未决的问题**。先记住节奏：Chrome 从 **153** 起改为**两周一个稳定版**，所以「157 刚发、158 已 Beta、159 在 Dev」是正常的。悬着的那件事是 **WebMCP**：它的 **origin trial 覆盖 Chrome 149–156**，也就是说**试用期已经结束**——一旦试用结束，已经上线的站点**没法再通过 token 给访客开这个 API**，只剩两条路：Chrome 157 默认开启，或者退回 `chrome://flags` 手动打开。截至今天，chromestatus 把 157 列为「预期发布里程碑（desktop / Android / WebView）」，但**官方并没有发出「默认开启」的公告**，已有分析认为会滑到试用延长。跨浏览器侧的态度决定了它短期不可能成为可依赖的东西：**Edge 有自己的 trial 到 11-17 截止**（且明确可能「永不超出试用范围」）、**Firefox 已拒绝**、**Safari 明确反对**（WebKit 在 standards-positions 里给的是 negative）。**给站点的建议不变，而且更硬了**：把 WebMCP 当作**渐进增强**（`document.modelContext` 存在才注册工具），主路径仍然要留 DOM 操控 / API / CLI；不要把它写进对外承诺。

### 🚀 框架与工具链

- **[Claude Code v2.1.317：成本报表、子 Agent 的 effort 改成「按模型存档」，Read 的存根被删](https://code.claude.com/docs/en/changelog)**（2026-11-02，约 87 项变更：62 修复 / 10 新增 / 8 改进 / 6 变更 / 1 移除）：这一版量很大，挑对线上有影响的四条。**一、成本可查了**：Claude apps gateway 的管理 API 新增 **`GET /v1/organizations/analytics/cost`**，并按 **IdP 组出每日记录**——配合 10-31 那版加的组预算（`pooled_budget`），企业侧「谁花了多少、超没超」第一次能闭环。**二、自托管 runner** 新增 `CLAUDE_CODE_DISABLE_NESTED_SESSION_ID`，避免嵌套会话 ID 串号。**三、语义变化**：当子 Agent 跑在**与主会话不同的模型**上时，现在用它自己那份**已保存的 effort 档位**，而不再继承会话的——这会改变「同一套 prompt 在不同模型上的行为一致性」，如果你依赖继承，需要显式设置。**四、安全相关的体验改动**：shell / web 工具在**把账户邮箱发到网络之外**之前会先弹确认；Agent SDK 的 hook 支持 `onFailure: "block"`。另一个容易被忽略的移除：**Read 工具的「文件自上次读取后未变更」存根被删掉了**——依赖这个提示做判断的脚本会失效。其余是自托管 runner、VS Code、云会话、Windows 与 OpenTelemetry 的批量修复。⚠️ 昨天那版（2.1.316）刚把 Opus 4.8 的 fast mode 标为 **11-30 移除**，这两条要一起排期。

### 🤖 AI 与开发

- **[Anthropic 修订招股书：Q3 营收 169.6 亿美元、同比近 12 倍，但环比增速从 144% 掉到 47%](https://thenextweb.com/news/anthropic-ipo-filing-17bn-revenue-commitments)**（修订版 S-1 于 2026-11-02 提交，初版 10-26）：这组数字之所以重要，是因为它同时给出了「爆发」和「减速」两个事实。**营收**：Q3 **$16.96B**，同比约 **+1,127%**（近 12 倍），前三季合计约 **$33.2B**；但**环比增速从 Q2 的 144% 掉到约 47%**，这才是投资人真正在定价的东西。**亏损**：Q3 净亏损 **$23.3B**，其中约 **$21.9B** 是**可转换票据的非现金公允价值变动**（主要持有方是亚马逊），与估值上升挂钩；真正看经营的是**营业亏损 $567M**——对比 Q2 的 **+$974M 营业利润**，也就是**由盈转亏**。**支出承诺**：总额 **$895.4B**（以算力与基础设施为主），其中约 **$70B** 在 12 个月内到期、约 **$448B** 到 2030 年底、其余落在 2031–2045。**上市安排**：纳斯达克代码 **ANT**，高盛与摩根士丹利牵头、另有约 20 家投行，目标在**感恩节（11-26）之前**挂牌，募资规模瞄准 SpaceX 的纪录 **$86.2B**。**估值**：投资人讨论的公允区间是 **$1.4–1.5 万亿**，低于此前流传的约 **$2 万亿**。⚠️ 两个口径陷阱：一是「净亏损同比扩大还是收窄」在不同媒体那里结论相反（有以 Q2 的 $66.3B 为对照说收窄，有以去年同期 $12.1B 为对照说扩大），本质是**净亏里塞了巨额非现金项**；二是**营业利润转负**这个信号比营收增速更该被盯住。
- **[OpenAI 发布 LifeVal：用 169 个「日常生活任务」考 AI，而不是考答题](https://openai.com/index/lifeval/)**（2026-11-02）：这条对做 Agent 产品的人有直接参考价值，因为它把评测从「问答」搬到了**带工具的真实流程**上。构成：**169 个 agentic 任务**，允许浏览、电脑操作与 connector，按**场景化的 rubric** 打分，覆盖 7 个领域——照护、健康、教育、家庭行政、个人财务、购物、政务。任务来源不是拍脑袋，而是基于**美国时间使用调查（ATUS）**与**多国时间使用研究（MTUS）**，加上 OpenAI 自己对 **3,995 名**人口学代表性受访者的调研。主指标是 169 个任务的平均 reward。分数：**GPT-6 Astra（2026-09）约 80.6%**，而 **GPT-5.2（2025-12）只有 49.3%**；但值得注意的细节是**从 GPT-5.4 到 GPT-6 Astra 只涨了 7.6 个点**，官方称这三个版本间「进展停滞」。单项示例：找到新住处 100%、洪水备灾志愿者调度 98.0%、远程陪奶奶看球 96.3%、幼儿园入学报名 93.1%、糖尿病饮食准备 90.4%。⚠️ 保留：这**基本仍是 OpenAI 的内部评测**——完整任务集、打分代码、误差棒与可复现的榜单都没放出，GPT-6.1 Sol / Terra 也还没进图，所以只能当「趋势」看，不能当「排名」用。

### 📚 好文精选

- **[WebMCP 跑在我的博客上，而 Apple 在反对整个想法](https://botmonster.com/web-dev/webmcp-browser-tools-for-ai-agents/)**（2026-11 上旬，实操 + 立场）：比规范文档好读得多的一篇，因为它把「一个站点要暴露工具给浏览器 Agent」这件事**从头做了一遍**。值得抄的三点：**第一，作者对「恶意调用方」的处理**——工具注册出去了，就要假设调用方可能是来套数据或诱导越权的，所以每个工具都要自己校验参数与权限，不能指望浏览器替你兜底；**第二，声明式写法（表单上的 `toolname` / `tooldescription` / `toolparamdescription`）比命令式更好维护**，因为它们跟着 DOM 走、天然和 UI 同步；**第三，它和 MCP 的关系被讲清楚了**——WebMCP 是把「站点自己的功能」以工具形式暴露给**浏览器里的 Agent**，而 MCP 是给**外部客户端**接后端能力，两者是互补而不是替代。配合今天的 Chrome 157 一起看：**现在能做的是「让站点在被支持时更快被理解」，不能做的是「把业务能力押在它上面」**。
- **[OpenAI 11-12 断供 Cursor：还有 9 天，你有三条路](https://tech.yahoo.com/ai/chatgpt/articles/openai-leaving-cursor-november-3-114720745.html)**（倒计时报道 2026-11-03；原决定 2026-08-28 ~ 29 宣布）：给还在 Cursor 里跑 GPT 的人一份清单。背景要交代清楚：**SpaceX 以约 600 亿美元收购 Anysphere/Cursor**（6 月达成、8 月完成交割）触发了合同里的**控制权变更条款**，OpenAI 随即宣布终止供货，理由是「无法确信 SpaceX 会按 OpenAI 的服务条款使用其技术」，并明确**即将推出的 Astra 系列完全不会供给 Cursor**；11-12 是合同允许的最长通知期。实际断掉的是**官方供货渠道**（Cursor 内置、按合同采购的 GPT 模型）。三条路：**① BYOK**，用自己的 OpenAI API key——但注意**覆盖不了 Tab 自动补全、Auto、Cloud / Background Agents、Automations、CLI 与 API/SDK**；**② 在 Cursor 里装 Codex 的 IDE 扩展**，绕开 Cursor 自己的模型通道；**③ 留在 Cursor 换 Claude 或其他模型**。双方的口径也记一下：Cursor CEO Michael Truell 称 OpenAI 模型只占 Cursor 流量的约 **5%**、谈判仍在进行；Anthropic 的 Tom Brown 则表示会**为 Cursor 增加 Claude 的算力**。⚠️ 收购与断供的细节以两家官方声明为准，目前主要来自媒体报道。
