### 🎨 浏览器与 CSS

- **[Chrome 156 稳定版](https://chromestatus.com/release-notes/156)**（2026-10-20，13 项默认启用）：这是两周节奏下又一个功能版，不是补丁版。
  - **CSS `random()`**：浏览器原生生成区间随机值，`top: random(0%, 100%)` 就能把元素撒开；支持传 `<random-key>` 控制多个属性/元素之间是否共享同一个随机值——过去这类「每次刷新位置不同」的效果要么写 JS，要么用超长 `nth-child` 列表。
  - **IndexedDB 底层换成 SQLite**：替换掉老旧的 LevelDB + 扁平文件混合结构，**Web API 不变**，主要收益是可靠性。注意这是**分阶段上线的第 2 步**，只作用于**新建的数据存储**（首次访问或清过站点数据），已有 LevelDB 数据不受影响；同时**事务调度行为被调整为与 Firefox / Safari 一致**——如果你的代码依赖特定的事务交错顺序，这是唯一可能被观察到差异的地方。
  - 其余：`scroll-snap-type: pair`、单轴滚动容器、`text-decoration-inset`、`navigation-source` 伪类、注册自定义属性的可选 descriptor；网络侧支持可重试的模块加载失败、WebTransport 自定义请求/响应头；以及延续 Chrome 142 的**本地网络访问限制**。Chrome 157 全量稳定版 **11-03**。
- **[Firefox 159 Beta](https://www.firefox.com/en-US/firefox/159.0beta/releasenotes/)**（2026-10-12 进入 Beta）：Web 平台侧有四项值得盯——**Scoped Custom Element Registries**（终于能按作用域注册同名自定义元素，Web Components 生态喊了很久的能力）、**parse-time Sanitizer API**（解析时清洗，而不是事后操作 DOM）、**滚动驱动动画**（`animation-timeline` / `scroll-timeline` / `view-timeline`）以及一批 WebGL 扩展。同时**正式放弃 Windows 8.1 及更早版本、macOS 10.14 及更早版本**。按六周节奏，正式版应在 11 月中下旬。
- **WebMCP 的 origin trial 将在 11-17 结束**，目前计划**随 Chrome 157（11-03）正式发布**（chromestatus feature 5117755740913664）。API 已从早期的 `navigator.modelContext` 收敛为 **`document.modelContext.registerTool()`**，另有声明式表单写法（`toolname` / `tooldescription` / `toolparamdescription` / `toolautosubmit`）。⚠️ 标准状态要看清：它只是 W3C Web ML CG 的**社区草案**，**WebKit 已正式表示反对**（standards-positions #670）、Mozilla 中立——Chrome 先发不等于跨浏览器可用，做「让站点被 Agent 调用」的方案时仍需 DOM 操控或 CLI 作为兜底。

### 🧰 工程化与安全

- ⚠️ **[OpenCode Console 凭据泄露：1.4% 用户受影响](https://thehackernews.com/2026/10/opencode-console-breach-may-have.html)**（2026-10-16 夜间入侵，10-17 披露，10-19 ~ 20 持续发酵）：入侵者进入了 OpenCode Console 的**一套遗留系统**，可能读到用户填在其中的 **OpenAI / Anthropic / Google API key**。约 **1.4% 的 Console 用户**收到邮件（只波及「关联了外部 provider」的账号）；**本地 SQLite 里的 key 不受影响**。官方称事件与「大规模蒸馏攻击」有关，Anthropic 已吊销受影响的 Claude key。
  - 为什么值得单列：**provider key 是 bearer 凭据**——在 Console 里删掉不等于吊销，Console 的花费上限也管不住直接调用；已有用户报告被刷 **$281 / $168**。正确做法是去各家控制台**吊销并重建**、把新 key 推到所有依赖方（CI secret、脚本、本地环境），再回查 10-16 以来的账单。这已经是本月第三起「AI 编程工具把凭据变成普通文件」的事件（前有 npm Trusted Publishing 的 SlugFest 与 Tensorlake SDK 投毒）。
- **美国 DHS 要求联邦民事机构移除 DeepSeek**（2026-10-19 公开，据 Reuters / Bloomberg）：依据是一份 **7 月下旬签署的供应链安全令**，覆盖 DeepSeek 自身产品**以及集成其模型的第三方服务**，并限制新的联邦采购；**国防部下属机构豁免**。DHS 称其为「多向量威胁」，但未公布具体技术证据；中国外交部 10-20 回应反对「泛化国家安全」。对技术选型的影响是：**合规边界开始按「模型来源」划线，而不只按数据流向**——给政府/受监管客户做方案时，模型供应链要单独列一栏。

### 📚 好文精选

- **[我数了 647 条大厂前端 JD：AI 不再只是加分项](https://juejin.cn/post/7698254253442793507)**（2026-10-19 抓取）：作者抓了腾讯、字节、网易三家官网在招的前端社招岗共 **647 条**，对标题 + 职责 + 要求全文统计——**405 条（63%）提到 AI，331 条（51%）写进任职要求**；分厂差异极大：腾讯 24/26（**92%**）、网易 33/45（73%）、字节 348/576（60%）。74 条点名了具体工具：**Claude 35、Cursor 25、Copilot 25、TRAE 19、GPT 12、CodeBuddy 4**。331 条里硬要求 182、加分项 149，腾讯的硬:软 是 16:5。结论不复杂：**「会用 AI 工具」正在从差异化变成准入门槛**，而写进硬要求的那一半，才是真正拉开差距的地方。
- **[Redesigning source control at Anthropic](https://www.anthropic.com/engineering/redesigning-source-control)**（2026-10-13 工程博客，本周中文社区集中转载）：一篇少见的「AI 把基础设施逼到极限」的一手记录。Claude 写代码的速度让主仓**日合并量从 2026-05 的约 2,500 次涨到 9 月的 3 万次以上**，主分支历史约 **100 GB**、CI 每天约 2,500 万次 checkout；shallow clone、sparse checkout、promisor remote、几百个内部镜像全部试过之后仍然顶不住。
  - 自研的 **Scion** 用 **7 人 5 个月**落地：提交/合并/rebase 全部挪到服务端（没有 push）、用 **changeset + 写前日志**替代快照式树对象、稀疏虚拟化 checkout、内容寻址数据分布在 `scion-daemon → 区域 scion-cache → scion-server` 的分层缓存里（每层命中率 >99%），全系统不存在完整物化仓库、也没有 packfile；换来约 **200×** 的 CPU/内存占用下降、checkout 从分钟级到秒级、省下约 **25% 的 CI CPU**。配套还重写了 code review（Antique）和代码搜索。
  - 两个诚实的边界：**它不是通用 Git 替代品**，只适合「几万人或 Agent 集群量级」的超大单体仓；另外官方明确说，**早期内部版的 Claude 把 Git 摄取管线重写到内存减少 20 倍、速度快 4 倍**——这套系统本身也是 AI 参与造的。
