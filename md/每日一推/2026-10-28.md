### 🚀 框架与工具链

- **[Node.js 26 转入 Active LTS：Temporal 默认启用，支持到 2029](https://nodejs.org/en/blog/release/v26.0.0)**（2026-10-28 转 LTS，26.0.0 于 2026-05-05 发布）：从此企业环境可以正式上了，维护期到 **2029-04-30**。它带进来的东西值得一次性过一遍——**Temporal API 默认开启**（顶层全局、无需 flag，替代 `Date` 的时区与不可变语义），**V8 14.6.202.33**（`Map` / `WeakMap` 的 `getOrInsert()` / `getOrInsertComputed()`、`Iterator.concat()`），Undici **8.0.2**、libuv 1.52.1、ICU 78.3，`NODE_MODULE_VERSION` 升到 **147**（原生模块要重编）。**移除**的部分是升级的主要摩擦：`http.Server.prototype.writeHeader()`、旧的 `_stream_*` 模块、`--experimental-transform-types` 都没了，`module.register()` 进入运行时弃用（DEP0201 / DEP0203 / DEP0204）；构建要求提到 **GCC 13.2+ / Python 3.10+**。另外它是**旧奇偶节奏下的最后一个版本**，Node 27 的首个 alpha 同日开闸（发布模型此前于 **10-21** 推过）。
- 同一天值得顺带看一眼的还有 **Vite+ 1.0** 的中文报道热（统一 `vp` CLI 管运行时、包管理器与 Vite 8 / Vitest 5 / Rolldown / Oxlint / Oxfmt，`vp migrate` 支持 tsup，新增 GitLab CI/CD 与 Docker/Homebrew 分发）——但**它 9-28 就发了 1.0**，这轮是媒体跟进，按旧闻处理、不再单列。

### 🎨 浏览器与 CSS

- **[Firefox 159：滚动驱动动画默认开启，旧 masonry 语法被删](https://developer.mozilla.org/en-US/docs/Mozilla/Firefox/Releases/159)**（2026-10-27 发布，同时出 ESR 153.6.0 / 115.44.0）：最实用的一条是 **CSS 滚动驱动动画默认可用**——`animation-timeline`、`scroll-timeline`、`view-timeline`、`animation-range` 四件套齐了，Web Animations API 也补上 `ScrollTimeline` / `ViewTimeline` 与 `timeline` / `rangeStart` / `rangeEnd` 选项；按 caniuse 口径全球覆盖约 **88%**（Chrome 115+ 与 Safari 26 已有等价 WAAPI）。另一条是**清理**：直接删掉旧的 `masonry` 取值与 `masonry-auto-flow`，统一到 `grid-lanes` / `inline-grid-lanes`——和 **10-26** 推过的 Safari 27.2 把 `flow-tolerance` 改名 `fit-tolerance` 是同一次命名收敛，谁还在写旧语法的瀑布流现在可以动手了。安全侧一次修了 **167 个漏洞**；发布节奏从这一版起改为**双周**，Firefox 160 已在 beta、定档 **11-10**。其余是 Smart Window 页面抓取、侧边栏重排，以及 AMD Linux 上的显存占用修复。⚠️ MDN 的浏览器兼容数据记 Firefox 159，caniuse 却记 161，Playwright 自带的 Firefox 157 里 `CSS.supports()` 与 `ViewTimeline` 都还检测不到——**别只靠特性检测判断能不能用**。
