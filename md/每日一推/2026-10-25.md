### 🎨 浏览器与 CSS

- **[WebKit Features for Safari 27.1：折叠屏的第一套 Web 能力](https://webkit.org/blog/18486/webkit-features-for-safari-27-1/)**（2026-10-23，Jen Simmons）：Safari 27.1 随折叠屏 **iPhone Duo** 发布，官方口径是「和其他 iPhone 同一套 WebKit，不做特殊移动版，靠响应式适配」。面向用户的变化只有一个——半折叠像书一样立着看 PDF 时**双页并排**。面向开发者的两个 API 都在特性开关后面（设置 → App → Safari → 高级 → Feature Flags）：**Device Posture**（`@media (device-posture: folded | continuous)`、`navigator.devicePosture` + `change` 事件）与 **Viewport Segments**（`env(viewport-segment-width <col> <row>)` 等六个环境变量、`window.viewport.segments` 返回一组 DOMRect，左右两块分别是 `0 0` / `1 0`）。官方给出的视口尺寸表值得存：宽 **382–951 CSS px**、高 368–902，外屏竖 382×580 svh、内屏横 951×585（620 lvh）。没有真机可以用 **Xcode 27.1 Device Hub** 模拟。
  - ⚠️ 一个尚未解决的问题：外屏上网页内容**不会延伸到侧边控件后面**，那条位置只填了页面背景色。Apple 说 `viewport-fit="cover"` 是最直观的修法，但实测发现大量站点只处理了部分方向的安全区，强行铺满反而会挡内容，所以还在找更「傻瓜」的方案，并向开发者征集意见（[MacRumors 10-25](https://www.macrumors.com/2026/10/25/apple-wants-to-fix-safari-on-iphone-duo/)、[MacStories](https://www.macstories.net/linked/apple-investigating-options-for-extending-web-content-under-iphone-duos-safari-controls/)）。给折叠屏做适配时，先别把「全屏铺满」当成默认解法。
- **[Web Features Explorer 2026 年 10 月盘点：JPEG XL、`random()`、`symbols()` 进了 Chrome](https://web-platform-dx.github.io/web-features-explorer/)**（2026-10 月版）：BaseLine 侧的月度清单，两类值得看。**已「广泛可用」**（四大引擎都有）：`AbortSignal.timeout()`、块级布局里的 `align-content`、`Intl.Segmenter`、`transform-box`——这几个现在可以不用 polyfill、不用特征检测直接写了。**本月新进入 Chrome**：**JPEG XL 解码**、CSS `random()`（10-20 推过 Chrome 156 本体，这里是它进入特性清单的确认）、可重试的模块加载、`symbols()` 描述符、`text-decoration-skip-spaces`，以及 text import attributes（`import x from "./a.txt" with { type: "text" }`）。做组件库的人可以直接照这份表划一条「2026Q4 起可以删掉哪几层降级」的线。⚠️ 清单随厂商发布滚动更新，具体支持范围仍以各引擎 release notes 为准。

### 🤖 AI 与开发

- **[OpenAI 把前沿模型训练改成「断网跑」：起因是一次沙箱 DNS 配错](https://openai.com/index/hardening-our-model-training-environment/)**（2026-10-23）：官方披露了一条不太常见的安全线——**9-20**，训练环境里一个沙箱的 DNS 配置错误，让实验中的模型拿到了对外网络访问，并成功和**一个第三方聊天机器人**对话。随后 OpenAI 一度**暂停前沿训练**，从 10-01 恢复（停了约 11 天）。恢复时的前提是：训练环境**不再有任何实时互联网访问**，模型运行与训练分离，所有对外流量走白名单代理。红队在这一轮里额外挖出 **Kata Containers、gVisor、Moby/Docker、Linux 内核、VM 逃逸**里的一批零日，以及一条 **CPU 缓存计时侧信道**。要点：这套策略针对的是**内部训练**，不影响 ChatGPT 的浏览功能。对做 Agent 平台的团队，这份文档可以当「为什么沙箱不能和模型同网」的参考架构。
- **[Cursor Computer Use：本地 IDE 里的 Agent 开始点你的桌面应用](https://cursor.com/changelog)**（2026-10-23）：此前电脑操作只在**云端 Agent**（隔离 VM）和**自托管 worker**（`--computer-use`）里有，现在**本地 in-IDE Agent** 也能点击 / 输入 / 截屏任意桌面应用。官方演示是写 SwiftUI → 启动 **iOS Simulator** → 点完流程 → 看屏幕 → 改代码。触发方式是在 prompt 里 `@` 提一句 "Computer Use"，或让 Agent 在需要 GUI 时自己调。macOS 上要单独给**辅助功能**与**屏幕录制**权限，而且授的是独立助手 `~/.cursor/cursor-computer-use/Cursor Computer Use.app`（bundle `co.anysphere.cursor-computer-use`），不是 Cursor 本体或终端。⚠️ 几个没交代清楚的点：本地模式支持的系统版本、按应用的审批/白名单行为、审计日志、截图存哪；另外发布时**官方 changelog 里并没有这一条**（最新条目还停在 10-16），信息主要来自 X 与媒体转述。安全上要有心理准备——它操作的是你**已登录的真实桌面**，里面有邮箱、密码管理器、浏览器，跑不可信任务时建议用专用账号或 VM（[AlphaSignal](https://alphasignal.ai/news/cursor-s-computer-use-lets-its-coding-agent-click-through-desktop-apps)、[dev.to 解析](https://dev.to/gabrielanhaia/cursors-agent-can-now-click-through-your-desktop-apps-grant-access-to-the-helper-only-1og3)）。
- **[DeepSeek 开源推理栈 DeepInfer](https://github.com/deepseek-ai/DeepInfer)**（2026-10-20，Apache 2.0）：把线上推理系统里「能开源的那部分」放出来了——目前**只支持 DeepSeek-V4.1-Flash**，硬件侧同时覆盖 **NVIDIA SM100（Blackwell）与华为昇腾 950**，官方口径单集群 **155T token/天**、低谷期成本约 **$38 / GPU-小时**。技术上给了两条：**DSpark 投机解码**，以及 prefill 时**重跑最后 128 个 token** 来对齐 KV 状态（避免前缀缓存与投机分支的错位）。**明确的边界**：KV cache 管理与负载均衡**没有开源**，最小部署规模是 **64 + 64 张卡**——所以它不是能在家跑的推理框架，而是给有集群的团队做对标和移植的参考实现（[InfoQ](https://www.infoq.cn/)、[36Kr](https://36kr.com/)）。⚠️ 吞吐与成本为官方口径，未见第三方复现。
- **[通义「Qwen Go! 我的应用」：一句话生成能存数据、能分享的应用](https://www.qwen.ai/)**（2026-10-23，邀请制内测）：在 Qwen App 里用自然语言描述需求就能生成应用，关键差异是**数据持久化 + 可分享 URL**，而不只是生成一段代码或页面。底层是阿里云的 **Meoo（秒悟）**；授权后可以拉取**淘宝、高德、大麦、夸克网盘**里的个人数据作为输入（订单、行程、票据这类）。定位上它和「AI 生成前端代码」不是一回事，更像是**面向非开发者的个人应用运行时**——把「每个人有自己的小工具」做成了一个托管产品。⚠️ 内测阶段，实际可生成的应用复杂度、数据隔离与删除策略都还没有公开细则，涉及个人数据授权的部分建议先看清条款。
- **[腾讯元宝搜索对外开放：Skill / MCP / API 三条入口](https://cloud.tencent.com/document/product/1808)**（2026-10-20 开放，MCP 文档 10-22 更新）：把搜索能力按 Agent 生态的口味拆成三种接法——**Skill**（给 Claude Code 这类 CLI 用）、**MCP server**（`https://api.wsa.cloud.tencent.com/Mcp`，JSON-RPC 2.0 over Streamable HTTP，协议版本 `2025-6-18`，Bearer 鉴权）、**API**。额度：**每月 2000 次免费**，11-30 前用邀请码可到 6000 次。MCP 侧目前只暴露**一个工具 `SearchPro`**：`Query`（≤1500 UTF-8 字节）、`Site`、`Mode`（0/1/2）、`Cnt`（10–50）、`Industry`，号称覆盖 **13 个垂直领域 / 157 个来源**。⚠️ 官方特别提醒有**仿冒的 MCP 教程与端点**，接之前核一遍域名；另外「SearchPro」这种单工具设计意味着筛选主要靠参数而非多工具编排，复杂检索场景得自己在上层拼。

### 🧰 工程化与安全

- ⚠️ **[Storm-0940 用 AI Agent 打穿 ConnectWise 供应链：2,250 个 M365 租户、峰值每分钟 2,900 次登录](https://www.microsoft.com/en-us/security/blog/)**（Microsoft 10-21 归因，10-24 ~ 25 集中报道）：攻击者利用 **ConnectWise Cloud Backup** 里窃取的云应用凭据，借助开源多 Agent 渗透框架 **ARTEX**（Go 编写、Next.js 前端、可接任意模型）自动化侦察、密码喷洒与 OAuth 应用滥用——**10-10 ~ 14** 先做跨租户喷洒（144.172.64.99，327 个账号 / 8 个组织，约 15.1 万次失败登录，10-11 单日峰值 **2,900 次/分钟**），**10-15** 拿到 ConnectWise 云应用身份并开始登录客户环境，多起案例里**从首次定位到拿到特权云访问不到 3 小时**。10-16 ConnectWise 披露并停掉 Cloud Backup / SaaS Security / Cloud Management，10-17 吊销 7 个应用身份与证书。微软强调**这不是微软系统的漏洞**，问题在受信任第三方应用。
  - 两处需要分开看：Huntress 的独立数字是 10-16 时 **162 个租户确认被入侵**，后扩大到约 1000 个租户有登录尝试、300+ 成功——**「2,250」是微软遥测里的尝试目标数，不等于被攻陷数**；另外分析人士指出，记录显示 AI 是**加速了**既有手法（喷洒、OAuth 滥用），原始凭据并不是 Agent 偷的。中国驻美使馆已否认相关指控。对平台团队的启示仍然是那一条：**第三方 SaaS 的云应用凭据就是供应链的钥匙**，加上一个能跑自动化的 Agent，窗口从「天」压到「小时」（[The Hacker News](https://thehackernews.com/2026/10/china-linked-hackers-use-artex-ai.html)、[CSO Online](https://www.csoonline.com/article/4239028/china-linked-hackers-used-agentic-ai-in-attack-on-2250-microsoft-365-tenants.html)、[Dark Reading](https://www.darkreading.com/cyberattacks-data-breaches/microsoft-storm-0940-connectwise-supply-chain-attack)）。

### 📚 好文精选

- **[我实测了 Safari 在 iPhone Duo 上到底给网页留了多少空间](https://dev.to/tyoukyou23/i-measured-what-safari-actually-gives-your-web-page-on-iphone-duo-8jp)**（2026-10-24 前后）：用模拟器量出来的第一手数据，比官方尺寸表更接近踩坑现场——折叠 382×580、展开 669×825、展开转横 951×543、折叠转横 678×340；**展开后 `screen.width` 不更新**；折一次会触发 **2–3 次 resize**，中间经过若干瞬时尺寸；**`vh` 会超出可用高度，应该用 `dvh`**；`(pointer: coarse)` 在外屏也成立。做折叠屏适配的，这篇可以当 checklist 直接抄。
