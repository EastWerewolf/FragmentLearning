## 2026-10-16

**一句话速览**：ES2026 与 TypeScript 7.0 落地；Vite 8 全面转向 Rust 打包器 Rolldown，Vite+ 1.0 统一工具链发布（VoidZero 已加入 Cloudflare）；Tailwind Labs 加入 Shopify；Safari 27 带来官方 MCP Server。

### 🌐 语言与规范

- **[ECMAScript 2026 正式获批](https://www.infoworld.com/article/4193461/ecmascript-2026-specification-approved.html)**（2026-06-30，第 17 版）。新增一批实用方法：
  - `Math.sumPrecise()`：对可迭代数字求和，尽量减小浮点精度损失。
  - `Iterator.concat()`：惰性串联多个迭代器，无需先展开成数组。
  - `Array.fromAsync()`：从异步可迭代对象构造数组。
  - `Error.isError()`：跨 realm（iframe、`vm` 上下文）可靠识别错误对象，比 `instanceof` 更稳。
  - `Map` / `WeakMap.prototype.getOrInsert()` / `getOrInsertComputed()`：取不到就插入默认值，省掉 `if (!m.has(k)) m.set(...)` 样板。
  - `Uint8Array` 的 base64/hex 共六个方法：`fromBase64` / `fromHex` / `toBase64` / `toHex` / `setFromBase64` / `setFromHex`。
  - `JSON.parse()` 的 reviver 新增第三参数 `context`，可用 `context.source` 拿到原始文本，从而把雪花 ID 之类的大整数还原成 `BigInt`；配套 `JSON.rawJSON()`。
  - 注：`Temporal`（时区/日历新日期 API）是否计入 ES2026 各家说法不一，部分资料称其进入 ES2027 且已在 Chrome 144+/Firefox 139+ 可用，可提前试用。

- **[TypeScript 7.0 发布](https://devblogs.microsoft.com/typescript/)**（2026-07-08）：原生 Go 编译器（Project Corsa）落地，全量构建提速 **8–12 倍**（VS Code 125.7s → 10.6s），内存下降约 18%，编辑器打开报错文件从 ~17.5s 降到 <1.3s。注意：7.0 **暂无稳定的编程接口**（计划 7.1），typescript-eslint、Vue/Svelte/Astro 等框架工具链暂难以完全切换；`strict` 与 `esnext` 已成默认，6.0 的废弃项在 7.0 变为硬错误。

### 🚀 框架与工具链

- **[Vite+ 1.0 发布](https://voidzero.dev/posts/announcing-vite-plus-1-0)**（2026-09-28，VoidZero，已加入 Cloudflare）：用一个 `vp` CLI 统一 Node 运行时 + 包管理 + 前端工具链，把 **Vite 8、Vitest 5、Rolldown、Oxlint、Oxfmt、tsdown、Vite Task** 整合成一套栈，共用一份 `vite.config.ts`。命令：`vp create/install/dev/check/test/build/pack/run/env`；已采用者包括 Dify、Tiptap、BlockNote、Hono、Laravel 起始套件。底层工具提速显著：Oxc React Compiler 比 Babel 快 10 倍，tsgolint 比 ESLint 快 12–18 倍，Oxlint 快 50–100 倍，Oxfmt 比 Prettier 快 30 倍。
- **[Vite 8 + Rolldown 1.0](https://vite.dev/blog/announcing-vite8.html)**：Rust 打包器 **Rolldown** 于 2026-05-07 发布 1.0 稳定版，成为 Vite 的底层打包器，取代「开发 esbuild + 生产 Rollup」双打包器架构，比 Rollup 快 **10–30 倍**，兼容 Rollup 插件 API。真实案例：Linear 生产构建 46s → 6s。
- **[Vitest 5.0](https://vitest.dev/blog/vitest-5.html)**：安装体积更小（自带依赖）、v8 覆盖率更快，新增 `vitest doctor` 性能诊断与 Browser Mode 的 **Trace View**（把交互/断言录成 DOM 快照回放）；新增 `vi.when` API，Fake Timers 开始支持 Temporal API。
- **[MSW 3.0](https://github.com/mswjs/msw/releases)**（Mock Service Worker，2026-09-28）：**改为 ESM-only**，最低要求 Node 22；新增 **Vite 插件**、GraphQL 订阅、`msw/utils` 独立入口（如 `delay`/`passthrough`），并支持拦截页面导航与表单提交。
- **React 19.3**：新增 `react-dom` 的 `browser()` API，在 SSR 中调用会报错、在浏览器中解析为可用值；配合 `<Suspense>` + `use(browser())` 可把子树标记为「仅浏览器」。
- **[Tailwind Labs 加入 Shopify](https://tailwindcss.com/blog/tailwind-is-joining-shopify)**（2026-09-09）：Tailwind CSS 及旗下开源项目仍是 MIT 许可并由原团队（含创始人 Adam Wathan）在 Shopify 内继续维护；Tailwind 将停止签约新的商业客户。背景是 AI 冲击：Tailwind 文档流量自 2023 年下降约 40%、收入一度下跌近 80%。目前 Tailwind CSS 每周安装量超 1.1 亿次。

### 🎨 浏览器与 CSS

- **乱序 HTML 流（Out-of-order HTML streaming）下沉到浏览器**：Chrome 150 起支持声明式 `<template for>` + 服务端流式 `<script type="text/html" data-for>`，无需 JS 驱动，Safari / Firefox 也将跟进。
