### 🚀 框架与工具链

- **[Bootstrap 6.0 Alpha 1](https://blog.getbootstrap.com/2026/10/08/bootstrap-6-alpha/)**（2026-10-08 发布，本周经 heise、前端周刊第 150 期集中报道）：距 v5 五年后的第一个大版本，改动比版本号看起来激进得多。
  - **定制模型换血**：改用 Sass 的 `@use` / `@forward` 模块系统，v5 里几乎全部 Sass 变量变成 Sass token map 里的 **CSS 变量**，于是主题可以在**运行时**在浏览器里改，不再只能编译期定死；提供 `defaults()` 合并覆盖。`$prefix` 被移除，前缀改由 PostCSS 在构建期加。
  - **类名语法转向 Tailwind 式前缀**：`.d-md-none` → `.md:d-none`、`.col-lg-6` → `.lg:col-6`、`.opacity-50-hover` → `.hover:opacity-50`、`.offcanvas-md` → `.md:drawer`。这是个迁移成本极高的破坏性变更。
  - **只支持现代浏览器**：Chrome/Edge 130、Firefox 132、Safari 18+，丢掉全部旧回退与 polyfill，直接用 `light-dark()`、`:has()`、`@property`、`@layer`、`@starting-style`、`oklch()`、`color-mix()`、`interpolate-size`、容器查询与原生 `<dialog>`。
  - **工具链**：JS 插件 **ESM-only**、TypeScript 作为源码语言、**Rolldown 取代 Rollup/Babel**、Vitest + Playwright 取代 Karma。另外附带 `llms.txt` / `llms-full.txt` 与给 AI Agent 用的 skill 文件（含迁移指南）——文档第一次把「机器读者」当一等公民。v5 仍有 5.4.0 与后续支持，作者称 v7 会来得更快。

### 🧰 工程化与安全

- ⚠️ **[SlugFest：npm Trusted Publishing 只绑「仓库 slug」，1,500+ 个包可被劫持](https://labs.cloudsecurityalliance.org/research/csa-research-note-npm-trusted-publishing-slugfest-20261014-c/)**（2026-10-13 披露，Bloom Security 发现，报告到公开隔了约 4 个月）：npm 把 Trusted Publishing 的信任绑在 GitHub 仓库的**可读 slug（`owner/repo`）**上，而不是不可变的 repository ID。仓库一旦被改名、删除或转移，**slug 就被释放**，攻击者可以抢先注册同名仓库、加一个文件名符合预期且带 `id-token: write` 的 workflow，直接拿到合法的发布凭据——不需要偷 token，也不需要内部人。受影响 **1,500+ 个包、累计 1,000 万+ 下载**，其中包含安全扫描器、认证工具与加密库。GitHub 已于 **10-02** 上线修复（未重新验证的 trusted-publishing 配置 48 小时后失效），暂无在野利用证据。研究方特别点出：**AI 编码 Agent 会放大这类风险**——每台开发机每月自动安装约 70 个包、到开发者本地可达 350 个，恶意依赖进入项目时根本没人看。
- ⚠️ **[Tensorlake npm SDK 被投毒：专门偷 AI Agent 凭据](https://www.orcarouter.ai/blog/2026-10-08-tensorlake-npm-sdk-compromise)**（2026-10-08，Shai-Hulud 变种）：`tensorlake@0.5.144` 经项目自己的发布流程发出，**带有有效的 Sigstore  provenance**（所以只查签名完全无效）——因为它的 GitHub 仓库在此前约 20 小时已沦陷。`preinstall` 钩子拉下 Bun 执行混淆过的 `setup.mjs`，扫的是 `~/.claude.json`、`~/.kiro/settings/mcp.json`、SSH 密钥、`.npmrc`、云凭据、GitHub Actions secrets、K8s/Vault token 与浏览器钱包扩展。新增两个值得记住的手法：**死手开关**（`gh-token-monitor` 每 60 秒轮询 GitHub，一旦偷来的 token 被吊销就触发恶意处理器）与基于区块链的备用 C2。属于 ChainDrop / PolinRider 系列（Shai-Hulud 血统，400+ 个包）。**这意味着：装 AI 编程工具之后，凭据已经从「云端密钥」变成「你磁盘上的普通文件」，供应链攻击的收益上限被抬高了。**

### 📚 好文精选

- **[Stack Overflow 2026 开发者调查：62% 对 AI 正面，但只有 6.6% 敢让它做重要决定](https://survey.stackoverflow.co/2026/technology)**（2026-10-06 发布，本周中文周报与社区集中转载）：第 16 届，30,903 份有效问卷、169 个国家。
  - **语言**：JavaScript **62.0%** 连续第 12 年第一，SQL 58.4%、HTML/CSS 58.2%、Python 58.0%，TypeScript **43.8%** 排第 6，但「最受喜爱」度约 58%。TS 的采用高度依赖工作场景——职业开发者中 48.8%，学习者中仅 26.5%，且 88.6% 的职业 TS 用户仍在同时写 JS。
  - **AI**：62% 对 AI 至少略偏正面（每日使用者中 71%），但只有 **6.6%** 愿意把重要决定交给 AI——**信任是有条件的，前提是能自己核对**。最常用的 Agent 是 **Claude Code（66%）** 与 GitHub Copilot（59%）；LLM 使用率 Anthropic **74.4%** 对 OpenAI **74.1%**，未来想用的比例则是 49.0% 对 32.1%。
  - 另一组被 Business Insider 单独拎出来的数据：开发者倦怠与疏离感上升，是「AI 重塑工作方式」的直接反应。
- **[GitHub 日榜被「一个人矩阵」污染：10-18 趋势榜拆解](https://wangruofeng007.com/blog/2026-10/github-trending-daily-1018-board-pollution)**：作者发现当天榜单前列有多个仓库来自同一账号矩阵，并把 `harness2` 从第 25 冲到第 2（+2,611 star）的过程逐帧拆开。结论对做技术选型的人有用：**趋势榜是增长手段的产物，不是质量的度量**——10-18 的日榜里，Claude Code 插件目录、agent skills、agent 记忆这几类仓库集体冲高，其中多少是真实需求、多少是榜单运营，值得先查提交记录再决定要不要用。
