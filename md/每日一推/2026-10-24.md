### 🚀 框架与工具链

- **[Bun 1.4.4：修 node2shell、撤销被攻陷的 CA，还内置了格式化器](https://bun.com/blog)**（2026-10-22）：安全侧跟着 Node 一起补——**CVE-2026-111497（node2shell）** 的 Brotli 解码器越界写，Bun 把 brotli 升到 1.2.1；同时**撤销 8 张 eMudhra / emSign 中间 CA**（10 月密钥泄露），`fetch`、`bun install`、`node:https`、WebSocket、HTTP/3 全链路拒绝含这些公钥的证书链，`bun build --compile` 的产物需要重编。功能侧意外地厚：新增内置 **`bun fmt`**（Prettier 兼容，官方称 286× 快——59.7ms vs Prettier 17.1s，支持 `--check` / `--staged` / `--doctor`，约 99.1% 测试套件兼容）；`bun check` 在大仓上大幅提速（MUI docs 10.28s → 1.31s）；`bun install` 补了指数退避重试、Yarn Berry lockfile 迁移、peer 依赖解析与 133 项修复。⚠️ 它现在按 `jsxImportSource` 转译 TSX，部分 Solid 测试设置会因此失败。
- **[Vite 8.3.5](https://github.com/vitejs/vite/releases/tag/v8.3.5)**（2026-10-21）：8.x 线的常规补丁，但几项值得扫一眼——**bundled-dev 把 `server.origin` 应用到资源 URL**、fallback 页声明 UTF-8、HMR 在「已不再被 import 的模块」处停止传播；**CSS 的 `url()` 里出现字面量 `%` 不再报错**；optimizer 会扫描 `oxc.jsxInject` 注入的 import；resolve 支持带多个 `#` 的 subpath imports；chunk import map 补上缺失项并把 preload 依赖计入哈希。另外这一版把 lint 迁到了 **Oxlint**。注意它和 6.4.4 / 8.3.3 的安全修复不是一回事，安全升级仍要落到对应版本线。

### 🎨 浏览器与 CSS

- **[Safari Technology Preview 255](https://webkit.org/blog/18482/release-notes-for-safari-technology-preview-255/)**（2026-10-22，macOS Golden Gate / Tahoe）：功能清单不短——原生 `<select>` 外观里开始支持 **`<button>`**、SVG `<textPath>` 新增 **`side` 属性**、SVG 文本启用 inline 布局引擎、`cross-origin-isolated` 进入 Permissions Policy、可把 stream 转移给 AudioWorklet，Web Inspector 还加了 **CSS keyframe 动画编辑器**。真正值得 CSS 作者注意的是它花了 **15 个独立修复在 `line-clamp`** 上：浮动/内容溢出、省略号位置、`line-clamp: auto` 行为都在这一版收口。顺手修了 `font-family: initial` 表现成 `inherit`、`@starting-style` 里的 `revert`、shadow tree 中 `:visited` 不更新、`@scope` 失效等问题；移除了从未实现的 `document.implementation.createCSSStyleSheet()`。

### 🤖 AI 与开发

- **[Claude Code v2.1.310：Monitor 扩到 Bedrock / Vertex / Foundry](https://code.claude.com/docs/en/changelog)**（2026-10-23）：距 309 只隔一天，主线是把 309 的安全修复推到企业环境——**Monitor 工具与插件 monitor 现在在 Bedrock、Vertex、Foundry 上可用**，在关闭遥测 / 非必要流量的会话里也可用，并且同样**拦截长时间的前台 sleep**。网关兼容性改善：遇到不认 `effort-2025-11-24` beta 值或会话中途 system message 的兼容服务端，会自动去掉这些字段重试。安全侧补了一个 Windows 上的**静默绕过**——Git Bash 缺失且 hook 命令只由引号字符串组成时，`PreToolUse` / `PermissionRequest` 会让工具调用直接通过。其余是压缩与清理：`Prompt is too long` 后不再保留过多 base64 / SVG 导致反复失败，`-p` 与 Agent SDK 的非交互会话压缩更省内存，`cleanupPeriodDays` 很大时不再误删最近的粘贴图片。企业侧把云会话与 Remote Control 权限加进了自定义角色。
- **[Codex CLI v0.164.0：`/presets`、企业 MCP 认证 GA](https://github.com/openai/codex/releases)**（2026-10-23）：从 0.163 之后走了 12 个 alpha 才发稳定版。四个实用项——**`/presets`** 提供十个编号槽位保存常用 prompt / slash command，存在 `tui.presets`；**`/model` 与 `/permissions` 支持行内写法**（同一行里直接指定模型、推理强度、速度与权限档）；**全屏 transcript 支持图片预览**（Kitty graphics / Sixel 终端直接渲染）；**Enterprise MCP 认证 GA**（Codex 账号授权、独立 MCP 登录 / IdP、需要 secret 的 OAuth client）。安全侧给远程 Bash 与 Zsh snapshot 加了**凭据遮罩**，macOS 沙箱补了大小写变体元数据路径与可替换符号链接的漏洞。Amazon Bedrock 配置向导默认开启；`agent_wake`（后台 Agent 唤醒空闲根会话）仍在 flag 后面。Vertex AI provider 在 alpha.11.1 出现但没赶上这版，预计 0.165。
- **[Google 开源 Gemini API CLI：让 Claude Code / Codex 直接调 Gemini 的生图与视频](https://aistudio.google.com/learn/introducing-the-gemini-api-cli)**（2026-10-22 ~ 23，预览）：Apache-2.0、零依赖单二进制。定位很明确——**不是给应用代码用的 SDK，而是给「有 shell 能力的 Agent」用的工具**：Claude Code、Codex、Cursor、Antigravity、OpenClaw 都能在命令行里调 Gemini 生成图片 / 视频 / 配音 / 音乐、分析 PDF、转写音频，或把复杂调研交给 Deep Research。设计上有个细节值得抄：**媒体文件写到磁盘、只把输出路径打印出来**，避免把二进制塞进 Agent 的上下文；支持 `--output-format json`、`--jq`、`--schema`、`--dry-run`，`--help` 自带用法说明。Google 的建议是生产代码仍用 typed SDK，CLI 面向终端工作流与自主 Agent。
- **[OpenAI Decisions API 转 GA：用 GPT-6 Luna 做「快速判断」](https://www.gadgets360.com/ai/news/openai-decisions-api-gpt-6-luna-model-public-release-price-capabilities-12225198)**（2026-10-22）：不是新模型，而是把 GPT-6 Luna 重新配置成低延迟的判断接口——官方称比走 Responses API 快约 **10 倍**，延迟从 1–3 秒降到 **100–180ms**。输出三种类型：`predicate`（0–1 概率）、`choice`（多选一）、`score`（按 rubric 打分），并返回置信度。GA 新增 GPT-Live 语音、prompt caching、直接 JSON 输入、图片入题、单请求最多 **400 个问题**、美 / 欧推理驻留与 ZDR / HIPAA。定价很激进：**输入 $0.10 / 百万 token、缓存输入 $0.01，输出不计费**。客户包括 Box、Datadog、Ramp、Speak（Speak 把动作间隔从 1.4s 降到 0.13s）。它对着的是 TypeSafe 的 Jev 所在「决策模型」赛道，公开基准上仍有落后项。
- **[Kimi K3.1 Pro / Highspeed 发布：2.8T 参数、1M 上下文，编程基准逼近 Opus 5.5](https://www.ithome.com/1/017/284.htm)**（2026-10-24）：K3 系列首次大升级，**2.8T 总参数 / 约 104B 激活**的 MoE（896 experts），**1M 上下文**，官方称是 K3 的后训练升级，重点提升编程、3D 创作、金融研究与长程 Agent 任务。自报基准：**Terminal-Bench 4.0 65.7%**（对照 GPT-6 Astra 58.2%、Claude Opus 5.5 66.4%）、Kimi Code Bench 3.0 长程 61.2%、BenchCAD（带工具）92.7%、OfficeQA Pro v2 64.4。定价 **¥13 / 百万输入、¥1.3 缓存、¥68 / 百万输出**（约 $2 / $10），Highspeed 同智能、输出快 2–3 倍、价格约 2 倍；**完整权重计划 11-04 前放出**。上线十分钟免费额度就被抢空。⚠️ 均为官方口径；中文报道多说「3 万亿级」，详细规格是 2.8T。
- **[Docker Harbor + Docker Sandboxes 转稳定：每个评测任务一台 microVM](https://www.docker.com/blog/harbor-docker-sandboxes-run-safe-reproducible-agent-evals/)**（2026-10-23 稳定）：Harbor 是 Terminal-Bench 背后的开源 Agent 评测框架，现在每个 eval 任务跑在**独立内核的 microVM** 里，而不是共享容器——Agent（Claude Code / Codex / Cursor 等）碰不到宿主机、其他任务或沙箱外的东西。网络策略可配：setup 阶段拉依赖，Agent 干活时收紧网络，保证不同 Agent 在同样条件下被测；云上实测 64 个并发任务，支持 Compose 多容器任务，也会标记「改测试 / 改分数文件」这类 reward hacking。安装 `uv tool install "harbor[sbx]"`。⚠️ 本地模式目前只支持 macOS / Windows，且公开数据里还没有启动开销与单任务成本的基准。

- ⚠️ **[PHP2Shell 进入「不升级就下线」阶段：NSA 与多国 CERT 给出最严口径](https://www.indiatoday.in/technology/news/story/php-is-cooked-us-govt-says-patch-or-else-shutdown-and-go-offline-immediately-3022418-2026-10-22)**（2026-10-22 ~ 23；漏洞本体此前于 10-23 推过）：NSA、FBI、英国 NCSC 与 ENISA 的口径一致——**如果无法立即升级，建议把系统下线直到能完整缓解**；临时措施（WAF、缩小攻击面配置）**不能替代打补丁**，8.1 及更早版本应直接替换。暴露面估算在 **130 万 ~ 190 万台**公网主机之间；PHP 占网站约 **69.3%**，其中约 **48%** 跑在没有官方修复的版本上（34.7% 还在 PHP 7/5/4，13.7% 在 8.0/8.1），PHP 8.2 也将于 **2026-12-31** EOL。Cloudflare、Fastly、AWS 与 watchTowr 都观察到百万级利用尝试，**最早的已知尝试在 10-17**，早于补丁发布；Wikipedia、Internet Archive、4chan 出现过短暂中断。还没升的，这周末就该处理。
